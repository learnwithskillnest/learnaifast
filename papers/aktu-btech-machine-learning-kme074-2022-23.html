UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester VII

Note: Attempt all Sections. If you require any missing data, then choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 10 = 20 marks

  1. Explain the applications of machine learning in industry 4.0.
  2. State the example of classification problem.
  3. Differentiate between Training data and Testing Data in ML
  4. Define the Polynomial Regression.
  5. Explain the Multidimensional Scaling.
  6. Define K-Means Clustering.
  7. Describe artificial intelligence (AI).
  8. What is the difference between Root Node & Decision Node
  9. Explain the meaning of reproduction in genetic algorithm
  10. Explain the difference between reinforcement learning and deep learning?

Section B

Q2. Attempt any three of the following · 10 × 3 = 30 marks

  1. Explain the Differentiate between Supervised, Unsupervised and Reinforcement Learning
  2. What is Support vector machine (SVM) and how does it work? Explain the advantages & Disadvantages of SVM.
  3. Show the application of Clustering in various sectors, discuss with following examples: Marketing, Insurance, & Earth-quake studies.
  4. Explain Backpropagation algorithm in artificial neural network (ANN) with suitable example.
  5. Discuss the Genetic algorithm (GA) with suitable example. Also explain its advantages and applications

Section C

Q3

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Explain with a neat diagram, application of ML in healthcare and Banking sectors.
  2. Show the machine learning how works with Netflix, Facebook, and amazon websites.

Q4

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Is regression a supervised learning technique? Justify your answer. Compare regression with classification with examples.
  2. What is regression in machine learning with example?

Q5

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Draw the cluster of following 8 points into 3 clusters:
    A1= (10,7), A2=(8,6), A3=(9,4), A4=(5,8), A5=(7,5), A6=(7,4), A7=(3,2),
    A8=(4,9).
    Use the k-means algorithm and Euclidean distance and take the Initial cluster centers are A2(8, 6), A4(5, 8) & A8 (4,9). The solution up to two iterations.
  2. Use the Nearest Neighbor clustering algorithm and Euclidean distance to
    cluster: A1=(5,4), A2=(2,5), A3=(8,4), A4=(5,8), A5=(7,5), A6=(6,4),
    A7=(1,2), A8=(4,9). Suppose that the threshold t is 4.
