AKTU MCA Big Data (KCA022) Question Paper 2021-22

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseMCA, Semester III
SubjectBig Data (KCA022)
ExamTheory Examination 2021-22 (odd semester)
Time · Marks3 hours · 100 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Attempt all Sections. If require any missing data; then choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 10 = 20 marks

  1. List down various Big Data Platforms.
  2. List down the characteristics of Big Data Applications.
  3. What do you understand by Map-Reduce?
  4. List down five characteristics of Big Data.
  5. What are the advantages of Hadoop?
  6. Explain the difference between structure and unstructured data.
  7. Explain Avro data serialization technique in MapReduce.
  8. What is Name node & Data node in Hadoop Architecture.
  9. What is Apache Spark?
  10. Difference between HDFS and Hbase.

Section B

Q2. Attempt any three of the following

  1. What are the benefits of Big Data? Discuss challenges under Big Data. How Big Data Analytics can be useful in the development of smart cities.
  2. What is HDFS? Illustrate the major blocks in HDFS architecture.
  3. Show on how a client read and write data in HDFS, Give an example code.
  4. What are NoSQL databases? What are the different types of NoSQL databases?
  5. What are the main tools used in Hadoop eco system?

Section C

Q3

Attempt any one part of the following

  1. What is Big data? Describe the main features of a big data in detail.
  2. What are privacy and ethical issues with Big Data?

Q4

Attempt any one part of the following

  1. What are the components of Hadoop. Discuss any two component in detail.
  2. With a neat diagram, describe the steps of Map reduce parallel data flow.

Q5

Attempt any one part of the following

  1. How does HDFS ensure data integrity in a Hadoop cluster?
  2. What is Avro file based data structure. Illustrate with an example.

Q6

Attempt any one part of the following

  1. Which are the important features of MongoDB? Define Namespace in MongoDB.
  2. Discuss Hadoop YARN in detail with failures in classic Map-reduce.

Q7

Attempt any one part of the following

  1. Discuss the concept of regions in HBase and Storing Big data with HBase.
  2. Explain any three HiveQL DDL command with its syntax and example.
