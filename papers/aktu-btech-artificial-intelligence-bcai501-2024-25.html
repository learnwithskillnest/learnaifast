Answer hints

Q1(d). What is a CSP?

A Constraint Satisfaction Problem has a set of variables, a domain of allowed values for each, and constraints on which combinations are allowed. A solution assigns every variable a value without breaking any constraint. Examples: map colouring, Sudoku, timetabling.

Q2(a). Types of intelligent agents

Simple reflex agents act only on the current percept using condition–action rules. Model-based agents keep an internal state of the world, so they handle partial observability. Goal-based agents choose actions that reach a goal, using search or planning. Utility-based agents choose the action with the highest expected utility when several paths reach the goal. Give one example for each, such as a thermostat, a robot vacuum, a route planner and a self-driving car.

Q2(b). Uninformed vs informed search

Uninformed (blind) search uses only the problem definition: BFS, DFS, uniform-cost, iterative deepening. Informed (heuristic) search uses an estimate h(n) of the distance to the goal: greedy best-first and A*, where f(n) = g(n) + h(n). A* is optimal when h(n) never overestimates. Compare them on completeness, optimality, time and memory.

Q4(b). Sudoku as a CSP

Variables are the 81 cells, the domain is 1–9, and the constraints are all-different in every row, column and 3×3 box. Solve with backtracking search plus constraint propagation (forward checking or arc consistency), and pick the cell with the fewest remaining values first (MRV heuristic).

Q7(b). Tokenization in NLP

Tokenization splits text into units (words, subwords or characters) that later steps work on. The choice affects vocabulary size, how unknown words are handled, and accuracy. Subword methods like BPE and WordPiece, used by transformer models, split rare words into known pieces. Mention the challenges: punctuation, contractions, and languages like Hindi with complex scripts or no spaces.
