AKTU Big Data and Analytics (BCDS601) Question Paper 2024-25

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester VI
SubjectBig Data and Analytics (BCDS601)
ExamTheory Examination 2024-25 (even semester)
Time · Marks3 hours · 70 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Attempt all Sections. In case of any missing data; choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 7 = 14 marks

  1. Define Big Data. What are its key characteristics.
  2. Define the Hadoop Distributed File System (HDFS). How is it different from traditional file systems?
  3. What do you mean by MapReduce? List its main phases.
  4. Describe how compression techniques and file formats impact the performance of big data processing systems
  5. What is the role of file system interfaces in big data storage environments
  6. Explain briefly the role of YARN in the Hadoop ecosystem.
  7. What are the key differences between Hive and traditional SQL databases

Section B

Q2. Attempt any three of the following · 7 × 3 = 21 marks

  1. Describe its Big Data’s evolution over time. Discuss the key drivers behind the rise of Big Data.
  2. What is the role of Big Data analytics in intelligent data analysis.
  3. Explain the architecture and use cases of Apache Flume and Apache Sqoop in Big Data systems. How do these tools support efficient data ingestion from structured and unstructured sources
  4. Evaluate the trade-offs between real-time and batch processing in distributed systems. How do technologies like YARN and Spark support both paradigms
  5. Evaluate the use of Hive, Pig, and HBase for different Big Data application scenarios. When would you choose one over the others?

Section C

Q3

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Describe the importance and applications of Big Data in different industries such as healthcare, finance, and e-commerce. How does Big Data contribute to decision-making in these sectors?
  2. What are the major concerns related to Big Data privacy and ethics? Discuss how auditing and compliance play a role in addressing these concerns.

Q4

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Discuss the process of job scheduling and task execution in Hadoop. How does Hadoop ensure fault tolerance during task execution?
  2. What are HDFS block size and block abstraction? How do they contribute to performance in Big Data systems

Q5

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Design a data ingestion and transformation pipeline for a real-time social media analytics system using tools like Flume, Sqoop, and Avro.
  2. Explain the architecture and use cases of Apache Flume and Apache Sqoop in Big Data systems. How do these tools support efficient data ingestion from structured and unstructured sources.

Q6

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Evaluate the use of NoSQL databases in real-time big data applications. Discuss their strengths and weaknesses compared to SQL databases.
  2. Evaluate the performance benefits and limitations of Spark over traditional MapReduce in big data processing.

Q7

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Describe HBase and its data model. How does HBase differ from traditional relational databases, and what types of applications benefit most from using HBase
  2. Explain the process of data loading and querying in Hive. How does HiveQL differ from standard SQL, and what are its advantages
