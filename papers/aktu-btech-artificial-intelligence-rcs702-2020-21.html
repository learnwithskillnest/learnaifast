AKTU Artificial Intelligence (RCS702) Question Paper 2020-21

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester VII
SubjectArtificial Intelligence (RCS702)
ExamTheory Examination 2020-21 (odd semester)
Time · Marks3 hours · 70 marks

Note: Attempt all Sections. If require any missing data; then choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 7 = 14 marks

  1. What is heuristic function?
  2. Write the difference between supervised and unsupervised learning.
  3. List down the characteristics of agent.
  4. List some of the uniform search technique.
  5. Differentiate between forward and backward chaining.
  6. What is bay’s rule?
  7. Define reinforcement learning.

Section B

Q2. Attempt any three of the following · 7 × 3 = 21 marks

  1. Explain DFS algorithm with suitable example.
  2. Define a well-formed formula (wff) and List some of the rules of inference.
  3. What are Statistical learning models? Show with suitable example.
  4. Define PCA. Differentiate between Principle Component Analysis (PCA) and Linear Discriminant Analysis (LDA)
  5. Explain state space approach for solving any AI problem.

Section C

Q3

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Describe the four categories under which AI is classified with examples.
  2. List various components of natural language understanding process. Describe syntactic analysis and semantic analysis in brief.

Q4

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Explain Alpha-Beta pruning? Solve the following question-
  2. Discuss Constraint Satisfaction problem with an algorithm for solving a Cryptarithmetic problem BASE + BALL GAMES

Q5

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Explain resolution in predicate logic with suitable example.
  2. Trace the operation of the unification algorithm on each of the following pairs of literals:
    I. f(Marcus) and f(Caesar)
    II. f(x) and f(g(y))
    III. f(Marcus, g(x, y)) and f(x, g(Caesar, Marcus)).

Q6

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Define decision tree? Explain it’s with suitable example.
  2. How can use Expectation-Maximization (EM Algorithm) in machine learning? Explain with appropriate example.

Q7

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Give the block diagram of pattern recognition system. Explain in brief.
  2. What do you mean by support vector machine (SVM)? Explain in detail with suitable example.
