Section A

Q1. Attempt all questions in brief · 2 × 10 = 20 marks

  1. Write the applications of artificial neural network.
  2. Draw 2-4-2 feed forward neural network.
  3. List various tuning parameters in back propagation.
  4. If the net input to an output neuron is 0.54, compute its output when the activation function is binary sigmoidal.
  5. Describe the difference between fuzzy and crisp set.
  6. Explain linguistic variables in brief.
  7. Define universal set in fuzzy set theory with example.
  8. Describe fuzzy inference system.
  9. Describe strong α-cut fuzzy set.
  10. Define the L-R type Fuzzy numbers.

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Explain step by step procedure of back propagation learning algorithm in detail.
