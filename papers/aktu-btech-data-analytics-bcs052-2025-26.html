Answer hints

Q2(b). Linear regression for study hours

x̄ = 6, ȳ = 63.6. Σ(x − x̄)(y − ȳ) = 142 and Σ(x − x̄)² = 40, so slope b = 142 ÷ 40 = 3.55 and intercept a = 63.6 − 3.55 × 6 = 42.3. Equation: Y = 42.3 + 3.55X. At X = 7, Y = 42.3 + 24.85 = 67.15.

Q2(d). Decaying window, 35% retained

Records retained per minute = 0.35 × 120,000 = 42,000. Justify windowing: a stream is unbounded, so you can't store everything. A decaying window gives recent records more weight and lets old ones fade, which keeps memory fixed while still tracking current trends.

Q3(b). PCA variance from eigenvalues

Total = 4.5 + 2.8 + 1.2 + 0.4 + 0.1 = 9.0. Variance per component: 50%, 31.1%, 13.3%, 4.4%, 1.1%. Cumulative: 50%, 81.1%, 94.4%. So 3 components are needed to retain at least 90% variance.

Q4(a). Sliding window 200, slide 50, 1,000 elements

Number of full windows = ((1,000 − 200) ÷ 50) + 1 = 17. A smaller slide gives more frequent, fresher results but more computation per element. A larger window smooths results but adds latency before changes show up.

Q5(a). Frequent itemsets at 60% support

With 5 transactions, 60% support means a count of at least 3. Single items: A = 4, B = 4, C = 4, all frequent. Pairs: AB = 3, AC = 3, BC = 3, all frequent. Triple ABC = 2, not frequent, so it is pruned. Frequent itemsets: {A}, {B}, {C}, {A,B}, {A,C}, {B,C}.

Q7(a). Mean and standard deviation

Mean = 124 ÷ 6 ≈ 20.67. Squared deviations sum to about 215.33. Population SD = √(215.33 ÷ 6) ≈ 5.99; sample SD = √(215.33 ÷ 5) ≈ 6.56. State which one you use. The values are moderately spread around the mean with no outliers.
