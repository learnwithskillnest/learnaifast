Answer hints

Q1(c). Opening vs closing

Opening is erosion followed by dilation: it removes small bright objects and noise and smooths contours. Closing is dilation followed by erosion: it fills small holes and gaps and joins nearby objects. Both use the same structuring element.

Q1(g). SIFT

Scale-Invariant Feature Transform. It finds keypoints that stay the same when an image is scaled or rotated, and describes each with a 128-value vector. Steps: scale-space extrema detection, keypoint localisation, orientation assignment, and keypoint descriptor.

Q4(a). Erosion and dilation

Erosion shrinks foreground objects: a pixel stays 1 only if the structuring element fits entirely inside the object. It removes thin lines and noise. Dilation grows objects: a pixel becomes 1 if the structuring element touches the object at all. It fills gaps and thickens lines. Draw a small binary example with a 3×3 structuring element.

Q5(a). Region growing vs region splitting

Region growing starts from seed pixels and adds neighbours that meet a similarity rule (such as intensity within a threshold), so it builds regions bottom-up. Region splitting starts with the whole image and keeps dividing it into quadrants (a quadtree) until each region is uniform, then merges similar neighbours. Growing depends on good seeds; split-and-merge can give blocky boundaries.
