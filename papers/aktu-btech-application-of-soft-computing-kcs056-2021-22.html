AKTU Application of Soft Computing (KCS056) Question Paper 2021-22

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester V
SubjectApplication of Soft Computing (KCS056)
ExamTheory Examination 2021-22 (odd semester)
Time · Marks3 hours · 100 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Attempt all Sections. If require any missing data; then choose suitably.

Section A

Q1. Attempt all questions · 2 × 10 = 20 marks

  1. Define Soft Computing. How is it different from conventional computing?
  2. What is difference between auto associative memory and hetero associative Memory?
  3. Write down the applications of genetic algorithm.
  4. What is a self organizing map?
  5. What is a membership function in a fuzzy set?
  6. If A = {1/1, 0.7/1.5, 0.2/2, 0.6/2.5} and B = {0.2/1, 0.3/1.5, 0.7/2, 0.1/2.5} find the Algebraic sum of the given fuzzy sets.
  7. What are the basic components of ANN?
  8. What is meant by threshold logic unit?
  9. Why do we use bias function in neural network?
  10. What is Adaptive learning?

Section B

Q2. Attempt any three parts of the following · 10 × 3 = 30 marks

  1. How crossover used in a GA? Explain the types of crossover with example.
  2. How is weight adjustment done in back propagation network?
  3. What is Defuzzification? Explain all the three methods which are used in Defuzzification with an example?
  4. What is Multilayer perceptron? How is different from single layer perceptron?
  5. Discuss neuro fuzzy system and rule base structure identification in detail.

Section C

Q3

Attempt any one part of the following · 10 × 1 = 10 marks

  1. How back propagation network works in ANN? Write an algorithm for it.
  2. Explain supervised and unsupervised learning in detail.

Q4

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Why preceptron is not able to handle the tasks which are not linearly separable? Justify your answer using XOR Problem.
  2. Write a short notes on the following: (i) Feedback control system (ii) Fuzzy Automata

Q5

Attempt any one part of the following · 10 × 1 = 10 marks

  1. Explain the architecture of Kohnen self organizing network.
  2. Explain Fuzzy Inference System with all its components in detail.

Q6

Attempt any one part of the following · 10 × 1 = 10 marks

  1. How can Fitness functions be found for any optimization problem? Maximize the function f(x)=x2 , with x in the integer interval [0,31) with the help of Genetic Algorithm.
  2. What is Genetic Algorithm? Discuss the working of Genetic Algorithm with the help of flowchart.

Q7

Attempt any one part of the following · 10 × 1 = 10 marks

  1. What are fuzzy sets? Discuss the various properties of fuzzy sets?
  2. Write short note on the following: (i) Fuzzy Controllers (ii) Fuzzy and Crisp relations
