Answer hints

Q1(c). Support vectors in SVM

Support vectors are the training points that lie closest to the decision boundary (hyperplane), on the edges of the margin. They alone decide where the hyperplane sits: remove any other point and the boundary doesn't change. SVM chooses the hyperplane that maximises the margin, the distance to these support vectors.

Q1(d). Gradient descent delta rule

The delta rule trains a linear unit by reducing the squared error E = ½ Σ (t − o)². Each weight moves a small step against the error gradient: Δwᵢ = η Σ (t − o) xᵢ, where η is the learning rate, t the target and o the output. Unlike the perceptron rule, it still converges to the best-fit weights when the data is not linearly separable.

Q1(h). Lazy vs eager learning

Lazy learners (KNN, case-based reasoning, locally weighted regression) store the training data and do the work only when a query arrives, so training is fast and prediction is slow. Eager learners (decision trees, neural networks, SVM, Naive Bayes) build a general model during training, so prediction is fast but the model is fixed in advance.

Q1(j). Offspring, chromosome and genes in GA

A chromosome is one candidate solution, usually written as a string such as 101101. Genes are the individual positions in that string, each encoding one part of the solution. Offspring are the new chromosomes created from selected parents through crossover and mutation, forming the next generation.

Q2(c). Information gain vs gain ratio vs Gini index

Information gain (used by ID3) is the drop in entropy after a split, but it favours attributes with many values. Gain ratio (used by C4.5) divides gain by the split information to correct that bias. Gini index (used by CART) measures impurity as 1 − Σ pᵢ² and is cheaper to compute because it has no logarithm. In an answer, give each formula, one small worked example, and which algorithm uses it.

Q7(a). Q-learning key terms

Cover agent, environment, state, action, reward, policy and the Q-table. The update rule is Q(s, a) ← Q(s, a) + α [r + γ · max Q(s′, a′) − Q(s, a)], where α is the learning rate and γ the discount factor. Key features: it is model-free and off-policy, and it balances exploration and exploitation (for example ε-greedy). Applications include game playing, robot navigation, traffic signal control and recommendation systems.
