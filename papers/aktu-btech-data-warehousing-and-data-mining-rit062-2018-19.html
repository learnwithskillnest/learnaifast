AKTU Data Warehousing and Data Mining (RIT062) Question Paper 2018-19

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester VI
SubjectData Warehousing and Data Mining (RIT062)
ExamTheory Examination 2018-19 (even semester)
Time · Marks3 hours · 70 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Attempt all Sections.

Section A

Q1. Attempt all questions in brief · 2 × 7 = 14 marks

  1. Define Data Mining?
  2. What is classification?
  3. Explain data generalization.
  4. Why is data preprocessing required?
  5. Define data compression?
  6. Explain Association rules.
  7. What is backup and recovery?

Section B

Q2. Attempt any three of the following · 7 × 3 = 21 marks

  1. Explain data cleaning and phases of data cleaning.
  2. What are the various requirements of clustering in data mining?
  3. How does a Snowflake schema differ from a STAR schema?
  4. Define the terms-- Aggregation, Historical Information and Query Facility.
  5. What is data warehousing with its advantages and disadvantages?

Section C

Q3

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Explain data integration, transformation and loading.
  2. Define data reduction? Write down the various strategies for data reduction.

Q4

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Find out the mean, variance and standard deviation for the height of animals 555mm,450mm,165mm,410mm and 300mm.
  2. Explain attribute relevance analysis with example.

Q5

Attempt any one part of the following · 7 × 1 = 7 marks

  1. How CURE is different from CHAMELEON.
  2. Explain Density-based and Grid-based clustering methods.

Q6

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Write down the difference between OLTP and OLAP.
  2. Explain various architectures of data warehouse.

Q7

Attempt any one part of the following · 7 × 1 = 7 marks

  1. Explain web mining and types of web mining with example.
  2. What are the essential differences between the ROLAP and MOLAP?
