Answer hints

Q1(b). Drivers of Big Data

Cheap storage and cloud computing, the growth of smartphones, social media and IoT sensors, and businesses wanting faster, data-driven decisions. Link them to the 3 Vs: Volume, Velocity and Variety.

Q2(d). New features in Hadoop 2.0

YARN separates resource management from processing, so engines other than MapReduce (Spark, Tez) can run on the cluster. Other features: NameNode High Availability with a standby NameNode, HDFS Federation (several NameNodes sharing the cluster), HDFS snapshots, and better scalability to thousands of nodes.

Q4(a). Working of MapReduce

Input is split into blocks. The Map phase turns each record into intermediate key–value pairs. Shuffle and sort groups all values with the same key and sends them to one reducer. The Reduce phase combines each group into the final output. Use word count as the example: map emits (word, 1), reduce sums the counts. Characteristics: parallel, fault tolerant, moves computation to the data.

Q5(a). Benefits and challenges of HDFS

Benefits: stores very large files across cheap machines, fault tolerance through block replication (default 3 copies), high throughput for batch reads, and data locality. Challenges: slow for many small files, not suited to low-latency access, files are write-once (append only), and the NameNode was a single point of failure before Hadoop 2.
