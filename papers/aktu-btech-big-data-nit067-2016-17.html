AKTU Big Data (NIT067) Question Paper 2016-17

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseB.Tech, Semester VI
SubjectBig Data (NIT067)
ExamTheory Examination 2016-17 (even semester)
Time · Marks3 hours · 100 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Be precise in your answer . In case of numerical problem assume data wherever not provided.

Section A

Q1. Explain the following · 10 × 2 = 20 marks

  1. List the characteristics of big data.
  2. How to calculate risk in marketing?
  3. Why would you use inferential statistics in big data?
  4. What do you mean by shrading?
  5. State the usage of Hadoop pipes.
  6. Compare Master-Slave and peer to peer architecture in NoSql.
  7. What is the purpose of bloom filter?
  8. Compare the classic Map Reduce with YARN.
  9. Mention the usage of Grunt.
  10. How Date and Time data types are used in Hive? (k) Why Hive is preferred instead of PigLatin?

Section B

Q2. Attempt any five of the following questions · 5 × 10 = 50 marks

  1. Relate crowd sourcing and big data. Justify the relationship with an example.
  2. Write down the aggregate data model in detail with an example.
  3. Differentiate “Scale up and Scale out” Explain with an example How Hadoop uses Scale out feature to improve the Performance.
  4. Discuss in detail about the basic building blocks of Hadoop with a neat sketch.
  5. Explain in detail about Map-reduce Workflows.
  6. Provide overview of HBase data model.
  7. Enumerate the rules followed while data modeling in Cassandra. How the relationships are handled in Cassandra?
  8. Write down the Hive queries for natural join and outer join. Give examples.

Section C

Attempt any two of the following questions · 2 × 15 = 30 marks

  1. (i) Explain with a neat sketch about the processing of a job in hadoop. (ii) List the various operational modes of hadoop cluster configuration and explain in detail about configuring/installing the hadoop in local/standalone mode.
  2. (i) Consider the student data File (st.txt), Data in the following format Name, District, age, gender. • Write a PIG script to Display Names of all female students • Write a PIG script to find the number of Students form XXXX District • Write a PIG script to Display District wise count of all male students. (ii) Explain the operators supported by pig w.r.to. data access, transformations and debugging operations.
  3. (i) Discuss the different ways of constructing version stamps. What are their pros and cons? (ii) Write in detail about the three dimensions of big data.
