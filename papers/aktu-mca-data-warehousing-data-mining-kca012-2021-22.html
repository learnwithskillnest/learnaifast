AKTU MCA Data Warehousing & Data Mining (KCA012) Question Paper 2021-22

UniversityDr. A.P.J. Abdul Kalam Technical University (AKTU), Lucknow
CourseMCA, Semester III
SubjectData Warehousing & Data Mining (KCA012)
ExamTheory Examination 2021-22 (odd semester)
Time · Marks3 hours · 100 marks
SourceAKTU question paper, from the ABESIT question paper bank
View original PDF Other years

Note: Attempt all Sections. If require any missing data; then choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 10 = 20 marks

  1. List down the Key Features of Data Warehouse.
  2. Define Data Mart.
  3. What is SMP?
  4. What is Master-slave processing?
  5. Briefly explain Association rules .
  6. Define Data cleaning.
  7. What is data Generalization?
  8. List down the various measures of Central Tendency.
  9. What are the characteristics of OLAP?
  10. Define Web Mining.

Section B

Q2. Attempt any three of the following

  1. What do you mean by Data Warehouse? Discuss the key features with suitable examples.
  2. What is data Warehouse implementation? What are the key considerations that are taken while finalizing the physical warehouse schema design?
  3. Describe the steps involved in data mining when viewed as a process of knowledge discovery.
  4. Describe Classification. Briefly Outline the major ideas of Bayesian Classification.
  5. Describe various OLAP operations with an example.

Section C

Q3

Attempt any one part of the following

  1. Write a note on Shared disk and Shared nothing architecture.
  2. What is multidimensional data model? How do we convert tables & spreads sheets to data cubes.

Q4

Attempt any one part of the following

  1. What do you mean by Workload matrix?
  2. Explain Attribute Relevance Analysis with an example.

Q5

Attempt any one part of the following

  1. Describe the basic architecture of data mining.
  2. Why data preprocessing is required in Data Mining. Explain.

Q6

Attempt any one part of the following

  1. What is clustering? List types of clustering. Explain any one approach for clustering.
  2. Describe CLIQUE algorithm.

Q7

Attempt any one part of the following

  1. Write short-notes on: (i) Crawlers (ii) Harvest System
  2. Explain & Define Markov Model.
