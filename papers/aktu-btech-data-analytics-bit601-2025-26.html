CourseB.Tech, Semester VI
SubjectData Analytics (BIT601)

Note: Attempt all Sections. In case of any missing data; choose suitably.

Section A

Q1. Attempt all questions in brief · 2 × 7 = 14 marks

  1. Explain structured vs semi-structured data.
  2. List the phases of the Data Analytics Lifecycle.
  3. Define multivariate analysis.
  4. Define Bayesian inference.
  5. What is stream data? Give one example.
  6. What is the Apriori algorithm?
  7. What are NoSQL databases?

Section B

Q2. Attempt any three of the following · 7 × 3 = 21 marks

  1. Explain the Data Analytics Lifecycle in detail with a neat diagram.
  2. Explain the linear regression model along with its assumptions. Using the least squares method, fit a regression line for the following data and obtain the equation of the line ( 𝑦 ൌ 𝑚𝑥 ൅ 𝑐ሻ. 𝐷𝑎𝑡𝑎: ሺ1,2ሻ, ሺ2,4ሻ, ሺ3,5ሻ, ሺ4,4ሻ, ሺ5,5ሻ
  3. Discuss the concept of filtering data stream processing. Explain Bloom filtering in detail.
  4. Provide an in-depth comparison between the CLIQUE and ProCLUS clustering algorithms. How do these methods handle challenges such as noise, outliers, and varying cluster shapes?
  5. Discuss the components of Hadoop ecosystem: Apache Hive, Apache Pig, Apache HBase.

Section C

Q3

Attempt any one part of the following · 7 × 1 = 7 marks

  1. What happens in the ‘model planning’ and ‘model building’ stages? How are these two different?
  2. Discuss the evolution of Big Data and need for data analytics in modern organizations.
